# THEHEGEO — GEOagents

Static landing page with animated canvas circuitry, rotating sphere and selectable organization layers. No build step or runtime dependencies.

Preview: run `python -m http.server 4173 --directory dist` then open http://localhost:4173.

Edit `dist/index.html`, `dist/style.css`, and `dist/app.js`. The logo and illustrations are recreated in code from the supplied screenshot. Fonts load from Google Fonts. Application buttons open informational dialogs; no backend is connected.
